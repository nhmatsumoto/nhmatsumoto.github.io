system-prompts-and-models-of-ai-tools

Coleção completa de system prompts, tools e modelos de AI tools como v0, Cursor, Devin, Replit e outros.

Fork da coleção mais abrangente de system prompts e definições de tools de ferramentas de IA para desenvolvimento de software.

Conteúdo

System prompts completos e definições de ferramentas de:

  • v0 (Vercel) — geração de UI
  • Cursor — IDE com IA integrada
  • Manus — agente autônomo
  • Same.dev — clone de sites
  • Lovable — geração de apps
  • Devin — engenheiro de software autônomo
  • Replit Agent — ambiente de desenvolvimento com IA
  • Windsurf Agent — editor com IA
  • VSCode Agent — Copilot Chat
  • Dia Browser — browser com IA
  • Trae AI — assistente de código
  • Cluely — AI overlay

Relevância

Estudar system prompts de produção revela padrões de engenharia de agentes:

  • Como diferentes ferramentas definem tool schemas
  • Estratégias de gestão de contexto e memória
  • Padrões de instrução para comportamento seguro
  • Trade-offs entre autonomia e controle do usuário

Relação com o ecossistema

Complementa o claw-code (análise técnica de agentes) e o gemini-cli (implementação de agente). Juntos, formam um corpus de referência para entender como agentes de código são construídos.

Problema e solução

Entender como agentes de IA são instruídos é fundamental para usá-los efetivamente e para construir os próprios. Esta coleção democratiza o acesso a system prompts que normalmente são proprietários e opacos.

Arquitetura

Repositório documental organizado por ferramenta. Cada diretório contém o system prompt completo, definições de tools/functions e, quando disponível, exemplos de interação e configuração de modelos.
