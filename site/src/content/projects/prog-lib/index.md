Biblioteca de referência com implementações de algoritmos e estruturas de dados fundamentais da ciência da computação.

### Conteúdo

Coleção organizada por categoria:

*   **Ordenação** — quicksort, mergesort, heapsort, radix sort
*   **Busca** — binary search, BFS, DFS, A*
*   **Estruturas** — listas, pilhas, filas, árvores, grafos, hash tables
*   **Grafos** — Dijkstra, Bellman-Ford, topological sort, MST
*   **Programação dinâmica** — knapsack, LCS, edit distance
*   **Strings** — KMP, Rabin-Karp, suffix arrays

### Propósito

Servir como material de consulta rápida e estudo, com implementações limpas e comentadas que priorizam clareza sobre otimização.

### Problema e solução

Algoritmos e estruturas de dados são fundamentos que precisam ser revisitados periodicamente. Ter uma biblioteca pessoal de implementações facilita a consulta rápida e reforça o entendimento dos conceitos.

### Arquitetura

Organizada por categoria, cada implementação é auto-contida com documentação inline explicando complexidade temporal e espacial, invariantes e edge cases.
