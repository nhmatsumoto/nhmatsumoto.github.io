# Design System Generator

## Instructions

I need you to create a comprehensive design system for my project with the following specifications:

### Brand Context
- **Brand name**: [BRAND_NAME]
- **Industry**: [INDUSTRY_TYPE]
- **Brand personality**: [professional, playful, modern, trustworthy, etc.]
- **Target audience**: [describe target users]

### Design System Components

#### 1. Color System
- Primary color palette
- Secondary/accent colors
- Neutral grays
- Semantic colors (success, warning, error, info)
- Light/dark mode variations

#### 2. Typography System
- Font recommendations (web-safe with fallbacks)
- Type scale (headings H1-H6, body, captions)
- Line heights and spacing
- Font weights available

#### 3. Spacing System
- Base unit system (e.g., 4px or 8px grid)
- Margin/padding scale
- Layout spacing guidelines

#### 4. Component Specifications
- **Buttons**: primary, secondary, ghost, disabled states
- **Forms**: inputs, selects, checkboxes, radio buttons
- **Cards**: containers and layouts
- **Navigation**: menus, breadcrumbs, pagination

#### 5. Accessibility Guidelines
- Color contrast requirements
- Focus indicators
- Text size minimums

### Output Format
1. Design tokens (JSON/CSS custom properties)
2. CSS utility classes
3. Component documentation with examples
4. Usage guidelines and do's/don'ts
5. Implementation guide for developers

Create a cohesive system that reflects the brand personality while maintaining excellent usability and accessibility.
