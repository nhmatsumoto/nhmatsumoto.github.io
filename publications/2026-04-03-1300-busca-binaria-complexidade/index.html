Busca Binária: Dividir para Conquistar

Explicação matemática e algorítmica da busca binária, provando sua complexidade O(log n) e implementando-a com segurança.

A Busca Binária é um dos algoritmos mais elegantes da computação. Ela resolve o problema de encontrar um elemento em uma **lista ordenada**, reduzindo o espaço de busca pela metade em cada iteração.

1. O Conceito Visual

Imagine que você está procurando um nome em um dicionário. Você abre no meio, vê se o nome está antes ou depois, e descarta metade do livro. Isso é busca binária.

2. Prova de Complexidade \(O(\log n)\)

A cada passo, dividimos o tamanho da entrada por 2. Se temos \(n\) elementos, o número de passos \(k\) para chegar a uma lista de tamanho 1 é:

$$\frac{n}{2^k} = 1 \implies n = 2^k \implies k = \log_2 n$$

O Perigo do Overflow (Padrão de Engenharia)

Muitos implementam o cálculo do meio como `(low + high) / 2`. Isso em linguagens como C++ ou Java pode causar overflow se a soma exceder o limite do inteiro. A forma segura é:

function binarySearch(arr: number[], target: number): number {
    let low = 0;
    let high = arr.length - 1;

    while (low <= high) {
        // Previne overflow e garante performance
        const mid = low + Math.floor((high - low) / 2);
        
        if (arr[mid] === target) return mid;
        if (arr[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}

Conclusão

A busca binária transforma um problema linear de 1 bilhão de registros em apenas **30 iterações**. Esse ganho logarítmico é o que permite escalas massivas em sistemas de busca e indexação.
