Olá, mundo!

Este é o primeiro post do novo formato do blog. A proposta é manter tudo simples: conteúdo versionado, HTML final legível e uma ferramenta local pequena o bastante para ser entendida rapidamente.

O que muda neste projeto

  • O conteúdo passa a viver em arquivos TOML.
  • O site público é gerado como HTML estático.
  • O fluxo de publicação acontece por git commit e git push.

O que esperar daqui

  1. Notas sobre arquitetura e produto.
  2. Publicações sobre tecnologia aplicada.
  3. Alguns registros sobre rotina, trabalho e estilo de vida.

Este espaço existe para durar com baixa manutenção.
