Pilhas e Filas: LIFO vs FIFO

Exploração das estruturas de dados fundamentais Pilha e Fila, detalhando os conceitos LIFO e FIFO com aplicações em recursão e buffers.

Estruturas de dados não são apenas formas de guardar informação, mas sim de **priorizar o acesso**. Pilhas e Filas regem comportamentos que vão desde o botão "voltar" do navegador até sistemas de mensageria assíncrona.

1. Pilha (Stack): O Conceito LIFO

O conceito **LIFO** (*Last In, First Out*) dita que o último elemento a entrar é o primeiro a sair. Pense em uma pilha de pratos: você sempre retira o de cima.

graph BT A["Push 1"] --> B["Push 2"] B --> C["Push 3 (Top)"] C -.->|"Pop (Sai primeiro)"| D["3"] style C fill:#00C2FF,color:#fff

A pilha é o motor da **Recursão**. Cada chamada de função é empilhada na *Call Stack* do sistema operacional.

2. Fila (Queue): O Conceito FIFO

O conceito **FIFO** (*First In, First Out*) rege que o primeiro a entrar é o primeiro a sair. É a base de qualquer sistema de atendimento ou processamento sequencial.

flowchart LR IN((Entrada)) --> Q1[1] Q1 --> Q2[2] Q2 --> Q3[3] Q3 --> OUT((Saída)) style Q3 fill:#00C2FF,color:#fff

Aplicações em Engenharia

Estrutura Lógica Uso Real
Pilha LIFO Undo/Redo, DFS (Busca em Profundidade), Histórico.
Fila FIFO Print Spooler, BFS (Busca em Largura), RabbitMQ/Kafka.

Implementação em TypeScript

// Pilha Minimalista
class Stack {
    private items: T[] = [];
    push(item: T) { this.items.push(item); }
    pop(): T | undefined { return this.items.pop(); }
}

// Fila Minimalista
class Queue {
    private items: T[] = [];
    enqueue(item: T) { this.items.push(item); }
    dequeue(): T | undefined { return this.items.shift(); }
}

Conclusão

Saber escolher entre uma pilha e uma fila é saber como o tempo e a prioridade interagem no seu algoritmo. Em alta escala, escolhemos **Filas** para desacoplar serviços e **Pilhas** para gerenciar estados locais complexos.
